# Project: Stark

**Description:** This is projects aims to bundle together different ML models and LLM's to create an agentic workflow that resembles Human Thought and Metacognition. Major thinking and desicion making happens in the Deterministic ( compared to llm's ) ML Models implemented in this project. LLM's are used for immitating the human subconsious wrt intuition and thought generation and natural language communication only.

## Capabilities:

1. This Thought Engine should be capable of matching the Current LLM's in terms of doing tasks, coding and Fact Retreival.
2. It should be able to Learn Facts and Procedures from PDF's and effectively utilize them in conversation.
3. It should be Near-Realtime with general queries and fact based questions
4. It should take negative feedback from user and be able to correct itself

## Task-Split:

### LLM Tasks:

1. Intuition/Thought Seeding
2. Natural Language Input and Output

### ML Tasks:

1. Fact Retreival 
2. Procedure Retreival 
3. Verifying and Following Procedures to Accomplish Task
4. Checking the Logic/Facts if LLM Generated Thought Seed
5. Nurturing Thought seed by carefully choosing the prompt sent to LLM
6. Identifying the Tone and Depth of answer based on a variad of factors
7. Storing Procedure information 
8. Self Thought with accumulated data to self-generate procedures **Future
